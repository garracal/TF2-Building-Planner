How it works

  • Layers: a map can have several stages. Each stage has points (A, B, C…), and each point has a RED and a BLU layout with its own buildings and spawns.
  • View mode (default): click a building to read its notes and screenshot, or click a control point to jump to that point's layout.
  • Edit mode: pick a tool, then click the map to place it. Drag to move. Click a building to add notes or a screenshot (upload or Ctrl+V). Sentries get a ⇋ button to flip them. Copy layout duplicates a layer to another point or team.
  • Moving around: mouse wheel or + / − to zoom, drag empty space to pan, Fit to reset. On touch screens, pinch and drag.
  • Shortcuts: Ctrl+Z undo, Ctrl+Y or Ctrl+Shift+Z redo, Delete removes the selected item, Esc deselects.
  • Sharing: Export / Import lets you confirm a title, author and short description (links work and preview on hover), then saves a map file with a cover image. The Library lists configs shared by others.
  • Saving: maps are stored only in this browser. Use Back up all maps now and then.

Export / Import

Export JSON lets you confirm the title, author and description, then saves the selected map (its images, points, buildings, notes and screenshots) as a .json file you can share or add to the library. Import JSON adds a map file or a backup as new maps and never overwrites anything.
